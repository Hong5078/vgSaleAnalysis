# Direction 1 — Regional Sales Trend Prediction from Genre + Platform

Predicts NA_Sales, EU_Sales, and JP_Sales independently, using only Genre,
Platform, and Year as predictors. Unlike the parent paper's setup, none of the
predictors are algebraically related to the targets (Global_Sales is not used
at all here), so there's no data-leakage shortcut for the models to exploit -
whatever predictive power we see is genuine.

## Files
- `analyze_regional_sales.py` - full pipeline: load, clean, explore, train, evaluate, plot
- `outputs/` - saved figures and metrics table (generated by running the script)

## Data
`../vgsales.csv` (classic Kaggle "Video Game Sales" dataset, 16,598 rows).
Columns used: Genre, Platform, Year, NA_Sales, EU_Sales, JP_Sales.

## Method
1. Drop rows missing Year or Genre.
2. One-hot encode Genre and Platform; keep Year as a numeric trend feature.
3. For each target region (NA, EU, JP) independently:
   - Train/test split (80/20, random_state=42)
   - Fit Linear Regression, Decision Tree Regressor, Random Forest Regressor
   - Evaluate MSE, RMSE, MAE, R^2 on the held-out test set
4. Compare feature importance (Random Forest) / coefficients (Linear
   Regression) across regions to see whether genre/platform preferences
   differ by market.
5. Plot sales-over-time trends by region and by genre to visualize the trend
   the models are trying to capture.

## How to run
```
pip install pandas scikit-learn matplotlib seaborn
python analyze_regional_sales.py
```
Outputs (figures + metrics CSV) are written to `outputs/`.

## Headline result
See `outputs/metrics_summary.csv` and the console output after running. In
short: Genre+Platform+Year explain a modest but real share of regional sales
variance (R^2 well below the parent paper's inflated 1.000, and that's
expected/correct here), and the best genres/platforms per region differ
between NA, EU, and JP - consistent with real regional market taste
differences rather than an arithmetic artifact.
