# Direction 2 — Predicting Critic/User Score from Genre + Platform + Year + Rating

**Research question:** How well can Critic_Score and User_Score be predicted
from a game's Genre, Platform, release Year, and ESRB Rating? And which of
the two (critic vs. user reception) is more predictable — and why?

This reframes the project from "predict sales" (which had a leakage problem
in the parent paper) to "predict reception". None of the predictors here
(Genre, Platform, Year, Rating) are algebraically related to Critic_Score or
User_Score, so there is no leakage risk in this framing either.

## Files
- `predict_scores.py` — Part A: regression models predicting Critic_Score
  and User_Score independently (Linear Regression, Decision Tree, Random
  Forest), with metrics and feature importance.
- `score_genre_analysis.py` — Part B: mean score by genre/platform, the
  critic-vs-user "reception gap" by genre, correlation between critic and
  user scores, and one-way ANOVA tests for whether genre/platform
  significantly affect each score.
- `outputs/` — saved figures and metrics tables (generated by running the
  scripts).

## Data
`../paper_replication/video_game_sales_and_ratings.csv` (Kaggle "Video Game
Sales and Ratings" by thedevastator, 16,719 rows). Critic_Score/User_Score/
Rating have substantial missingness (dropped for the relevant analysis only).

## How to run
```
pip install pandas scikit-learn scipy matplotlib seaborn
python predict_scores.py
python score_genre_analysis.py
```
