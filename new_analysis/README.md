## Key facts established in notebook 01
- Use `games.json`, not `games.csv`: the CSV header merges `Discount` and `DLC count`, which
  shifts every column. Trailer data (`movies`) is empty in this version.
- `estimated_owners == "0 - 0"` means SteamSpy has no record for that game, so it is a missing
  label, not zero sales. Labels stop updating around mid-2025, so the modeling set is games
  released on or before **2024-06-30** (76,727 labeled games after removing playtests, demos
  and software).
- Primary target: **hit = ≥100k owners** (10.7% of games). A 4-class ordinal target is also saved.
- Tags, reviews, playtime, CCU, DLC count, current price, Trading Cards and Family Sharing are
  excluded as post-release. Achievements, Workshop and Remote Play are held out as "uncertain".

## Key results from notebook 02
- The regression target is log10(owners) **relative to the release year**. On raw owners, test
  games average far fewer owners than training games (less time on sale, more competition), so
  just predicting the training mean scores R² = −0.22.
- Best leakage-free model (all store-page indicators, Random Forest): test R² = 0.235,
  hit ROC-AUC = 0.844.
- Most useful indicators inside the combined model: supported languages, price, store-page lead
  time, description text.
